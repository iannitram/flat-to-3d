## Conventions

- RVA = address minus image base. Offsets (`+0x...`) are byte offsets in the object.
- Pattern: hex bytes, `??` = wildcard (relative displacement). Each pattern was searched over the whole `.text` section and matches exactly once (count column in the table).
- Method abbreviations: **RTTI** = type descriptor `.?AV...@@` to its complete object locator to the vtable; **strxref** = RIP-relative `lea` to a string; **disasm** = capstone listing read by hand; **scan** = masked byte search over `.text`.
- `ZRenderVRDeviceDummy` is the object ("dummy"); `ZRenderVRDeviceBase` is its base ("base"). Vtable slot n is at vtable + 8n.
