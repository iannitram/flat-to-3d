### WP-01: Workspace reshape + frozen bones (pointer)

WP-01 was too large for one agent in one sitting (about 61 KB, about 60 files). It is now four parts. They run in this order inside wave 1, one agent and one branch per part, each depending on the one before:

| Part | File | What it lands |
|---|---|---|
| WP-01a | [WP-01a.md](WP-01a.md) | File moves (`inject/`, `app/` → `crates/`, the engine's inner moves, the `watch.rs` split), the root and crate manifests, `Cargo.lock`, the viewer and uevr-inject crate skeletons, the `docs/code-map.md` path rewrite, the 7 sanctioned test edits, `check.yml` |
| WP-01b | [WP-01b.md](WP-01b.md) | The exec split (`exec.rs`), the full leaf modules (`paths`, `fsx`, `sys`, `catalog`, `testing`, `state`/`switches` I/O, `recipes` route settings, viewer `frame`/`source`/`spec`) with their tests, and `tests/architecture.rs` |
| WP-01c | [WP-01c.md](WP-01c.md) | `cli.rs`: `parse_any`, the dispatch, `cli::COMMANDS`, `ok_exit` and the exit-code hook; the `cli/*.rs` entry points; the `api.rs` DTOs and `api::error_help`; `tests/cli_any.rs` |
| WP-01d | [WP-01d.md](WP-01d.md) | The stubs later WPs fill (wivrn, health_loop, injectors, wrapper, install, launch_options, face, the app pages), the real `wrapper::run_with` (A5 fix), the watch and `flat3d-run` wiring, the code-map stub rows, and the "Ownership after this WP" list |

Rules:
- **A "Depends on WP-01" means all four parts merged.** The same holds for "after WP-01", "WP-01 froze …" and "frozen by WP-01" in any other file: they mean the state after WP-01d.
- Each part leaves the tree compiling and passes its own done-check. WP-01b branches only after WP-01a has merged, and so on.
- The chain runs in parallel with WP-02 and WP-25a, which depend only on WP-00 and need none of the four parts.
- `Cargo.*` and `check.yml` are WP-01a's alone, and `Cargo.lock` is frozen once WP-01a has merged.
- Where the parts share a file (`lib.rs`, `cli.rs`, `api.rs`, `link.rs`, `injectors.rs`, the `watch/` files, `docs/code-map.md`), each part's file says which lines are its own.
- The `questions.md` entries for all four parts are under its `## WP-01` heading.
- Nothing is built from this file. A builder reads only its own part.
