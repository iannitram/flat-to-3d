### WP-10: Tether plans, runner errors, Wi-Fi sync

**Dropped 2026-11-10.** Reason: the owner ruled (ruling 42, `docs/notes/DECISIONS.md`) that Flat to 3D and Quest Tether stay separate apps. The owner plans stereoscopic glasses, so a wired-Quest internet tether compiled into the 3D app makes no sense, and Flat to 3D must not own the headset's internet link. This WP wrote the tether's plans (`tether/plan.rs`), its Wi-Fi sync (`tether/wifi.rs`), the `Tether` runner and the runner error strings. None of that is built, and none of it will be: WP-36 deletes the `tether` module that is already on main. Nothing from this WP is needed by any other WP. WP-09 (3D half) no longer calls `Tether::{set_wivrn,set_sleep,sync_wifi}`.

The file stays so the index and the history keep a place for it. The old body is in git history at the commit before this change.
