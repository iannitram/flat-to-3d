**Behaviour**
- **connect.** Call `unsafe { xr::Entry::load(&()) }`. In 0.22 it takes a `PlatformInfo`; Linux passes `&()`, which loads `libopenxr_loader.so.1`. A failure gives `NoLoader`.
  - Require `enumerate_extensions()?.khr_vulkan_enable2`.
  - `create_instance(&ApplicationInfo{application_name:"flat3d-viewer",application_version:0,engine_name:"flat3d",engine_version:0,api_version:xr::Version::new(1,0,0)}, &exts, &[], &())`.
  - `system(xr::FormFactor::HEAD_MOUNTED_DISPLAY)`: its error goes through `classify_system_err`. `ERROR_FORM_FACTOR_UNAVAILABLE`, `ERROR_RUNTIME_UNAVAILABLE` and `ERROR_RUNTIME_FAILURE` give `Retry`; any other code gives `Xr(r)`.
  - Check `graphics_requirements::<xr::Vulkan>`.
  - Vulkan: `ash::Entry::load()` at API 1.2, then `create_vulkan_instance(system, std::mem::transmute::<vk::PFN_vkGetInstanceProcAddr, openxr::sys::platform::VkGetInstanceProcAddr>(vk_entry.static_fn().get_instance_proc_addr), &ci as *const _ as _)`.
    - The annotated transmute is required: without it, clippy `missing_transmute_annotations` fails under `-D warnings`.
    - The types: ash `PFN_vkGetInstanceProcAddr` (ash-0.38.0 src/vk/features.rs:6) and openxr-sys 0.14.0 `platform::VkGetInstanceProcAddr = unsafe extern "system" fn(VkInstance, *const c_char) -> Option<unsafe extern "system" fn()>` (https://docs.rs/openxr-sys/0.14.0/openxr_sys/platform/type.VkGetInstanceProcAddr.html).
  - Then `vulkan_graphics_device`, then `create_vulkan_device` with `DEVICE_EXTENSIONS`.
  - Pick one graphics queue family. Wrap raw handles with `vk::Instance::from_raw(raw as u64)`.
  - `blend = enumerate_environment_blend_modes(system, PRIMARY_STEREO)[0]`.
  - The two `From` impls let `?` turn `xr::sys::Result` and `vk::Result` into `XrError`.
- **start.** `create_session::<xr::Vulkan>(system,&xr::vulkan::SessionCreateInfo{instance,physical_device,device,queue_family_index,queue_index:0})`, then `local = create_reference_space(LOCAL, Posef::IDENTITY)` and `view = create_reference_space(VIEW, IDENTITY)`.
- **pump_events.** Each `SessionStateChanged` goes through the pure `on_state`:
  - `READY` → `Begin`: `begin(PRIMARY_STEREO)`; the session is running.
  - `STOPPING` → `End`: `end()`.
  - `EXITING` or `LOSS_PENDING` → `Exit`: return `Pump::Exit`.
  - any other state → `Nothing`.
  - `ReferenceSpaceChangePending`: `Recenter`.
- **Swapchain.** One image, the same size as the frame.
  - Format from `pick_format(session.enumerate_swapchain_formats())`. Create flags `EMPTY`, usage `COLOR_ATTACHMENT|TRANSFER_DST|SAMPLED`, `sample_count/face_count/array_size/mip_count = 1`.
  - Recreate when the frame's (w, h, format) changes (`needs_recreate`). Drop the old swapchain only after `stream.end`.
  - `acquire` = `acquire_image()` + `wait_image(xr::Duration::INFINITE)`. The image arrives in `COLOR_ATTACHMENT_OPTIMAL`; the importer moves it to `TRANSFER_DST_OPTIMAL` and back before `release`.
- **Frame.**
  1. `waiter.wait()`, then `stream.begin()`.
  2. Take the newest source frame without blocking (`next(Duration::ZERO)`). If there is one: ensure the swapchain, acquire, `copy_to`, release.
  3. If there is no new frame, re-submit the last released image (quad layers allow this).
  4. Build two `xr::CompositionLayerQuad::new().space(&local).eye_visibility(xr::EyeVisibility::LEFT|RIGHT).sub_image(xr::SwapchainSubImage::new().swapchain(&h).image_rect(eyes[i]).image_array_index(0)).pose(pose).size(size)` and end with `stream.end(state.predicted_display_time, blend, &[&l, &r])`.
  - Leave `layer_flags` empty: the layer is opaque, and BGRx alpha is garbage.
  - With no swapchain yet, end with `&[]`.
  - `eyes` and `size` come from WP-17 `layout`; swap_eyes and crop are handled there.
    - `rects = layout::eye_rects(frame.width, frame.height, &spec)`.
    - Each eye is `xr::Rect2Di{offset: xr::Offset2Di{x: r.x as i32, y: r.y as i32}, extent: xr::Extent2Di{width: r.w as i32, height: r.h as i32}}`.
    - For the screen-capture sources (Gamescope, Portal), the picture is half-SBS/TAB, so `(w, h) = quad_size(unsqueeze(rects[0], spec.layout), screen_width_m)` (WP-17). The test pattern draws full-size eyes, so it uses `quad_size(rects[0], screen_width_m)`.
    - `size = xr::Extent2Df{width: w, height: h}`.
- **Recenter.** On the first running frame, on `Pump::Recenter`, and on SIGUSR1 (a `libc::sigaction` handler sets a static `AtomicBool`): `view.locate(&local, t)`, then `anchor = yaw_only(pose)`, `pose = quad_pose(anchor, distance_m)`.
- **import.**
  - `drm_fourcc_to_vk`: XR24 `0x34325258` and AR24 `0x34325241` → `B8G8R8A8_SRGB`; XB24 `0x34324258` and AB24 `0x34324241` → `R8G8B8A8_SRGB`; anything else → None. Use SRGB views so the blit does not encode twice.
  - `modifiers(ctx, f)`: the `DrmFormatModifierPropertiesListEXT` entries for `f` whose features include `TRANSFER_SRC|BLIT_SRC`. main passes them in the source `Offer`.
  - **`FrameData::DmaBuf{planes, modifier}`** (single plane only; `planes.len() != 1` → `ImportError::Unsupported`). Read `planes[0].{fd, offset, stride}`:
    1. Check `get_physical_device_format_properties2` + `DrmFormatModifierPropertiesListEXT` for `TRANSFER_SRC|BLIT_SRC`.
    2. Create the image with tiling `DRM_FORMAT_MODIFIER_EXT`, usage `TRANSFER_SRC`, `ExternalMemoryImageCreateInfo{DMA_BUF_EXT}` and `ImageDrmFormatModifierExplicitCreateInfoEXT{drm_format_modifier: modifier, plane_layouts:[SubresourceLayout{offset,row_pitch:stride,..}]}`.
    3. Memory type = `get_memory_fd_properties(DMA_BUF_EXT, fd)` ∩ the image requirements.
    4. Import with `ImportMemoryFdInfoKHR` using a **`libc::dup`** fd (Vulkan owns it), plus `MemoryDedicatedAllocateInfo`.
    5. Barrier: `src_queue_family_index=vk::QUEUE_FAMILY_FOREIGN_EXT` → ours, `old_layout GENERAL` → `TRANSFER_SRC_OPTIMAL`.
    - The dmabuf cache key is `libc::fstat(planes[0].fd.as_raw_fd())` → `(st_dev, st_ino)`, plus `modifier`.
  - **`FrameData::Mem{stride, bytes}`:** copy row by row (honouring stride) into a host-visible staging buffer, `cmd_copy_buffer_to_image` into the upload image, then continue as for DmaBuf.
  - Finally `cmd_blit_image` 1:1 (`Filter::NEAREST`) into the swapchain image, submit, and wait on the fence. `reset()` drops the cache when the format or size changes.
- **main.**
  - `split_until_pid(std::env::args().skip(1).collect())` strips `--until-pid N`. The rest goes to `ViewerSpec::from_args`. An error from either prints to stderr and exits 2.
  - Resolve the §2 defaults: `screen_width_m = if spec.screen_width_m > 0.0 { spec.screen_width_m } else { 3.0 }`, and `distance_m` the same way, defaulting to 2.5.
  - `PidWatch::open`: `libc::syscall(libc::SYS_pidfd_open, pid, 0)`.
    - `ESRCH`: exit 0 at once.
    - `ENOSYS`: fall back to `kill(pid,0)`.
    - `gone()` = `poll(POLLIN, 0)` reports readable.
    - The watch is checked every loop and during retries. When the pid is gone and a session exists, call `s.session.request_exit()`, then return exit 0.
  - Source from `spec.source`. Every capture source gets the same `Offer`:
    - `Offer{fourccs: vec![0x34325258, 0x34325241, 0x34324258, 0x34324241] /*XR24, AR24, XB24, AB24; BGRx first, no NV12*/, modifiers: import::modifiers(ctx, vk::Format::B8G8R8A8_SRGB), max_w: 7680, max_h: 4320}`.
    - `TestPattern`: `TestPattern::new(3840, 1080, spec.clone(), 60)` (WP-17).
    - `Gamescope`: `gamescope::open(&offer, Duration::from_secs(2))` (WP-18). `Ok(None)` gives `waiting-source` and a retry.
    - `Portal`: `portal::open(&token_path, &offer)` (WP-18), with `token_path = ${XDG_STATE_HOME:-$HOME/.local/state}/flat3d/portal-token`. `create_dir_all` its parent first.
    - `Auto` tries gamescope, then portal.
  - The loop feeds what happens to the pure `Supervisor`, and acts on the `Do` list it returns (print a status line, wait, or exit):
    - `PidGone` → `Exit(0)`.
    - `NoHeadset` (a `Retry` from connect) → `waiting-headset` when the state changes, then `Wait(2s)`.
    - `NoSource` → `waiting-source` when the state changes.
    - `Shown{w,h}` → `showing` with fps/w/h, when the state or size changes and every 5s. fps = frames shown since the last `showing` line ÷ the seconds since it.
    - `Fatal` → `error`, then `Exit(3)`.
    - `SessionExit` (`Pump::Exit`) → `Exit(0)`.
  - Status lines use WP-17 `status`: one JSON object per line on stdout, flushed.
  - Fatal errors: `NoLoader`, `Missing`, `Vk`, `Xr` (any code `classify_system_err` does not retry), a source `Err(String)` from `open` or `next()`, and any `ImportError`. Each prints an `error` status line and a stderr message (the error's Display), then exits 3.
  - Exit codes: 0 when the pid is gone or the session exits; 2 usage; 3 fatal.

**Tests:** CI runs clippy only (through `tools/check.sh`); there are no locked tests. The done-check runs these inline `#[cfg(test)]` tests with `--features xr`. They live in the xr-gated lib files, so they need no capture libs:
- `pick_format`: prefers B8G8R8A8_SRGB, falls back to R8G8B8A8_SRGB, None for UNORM-only.
- `needs_recreate`: None→true, same→false, a w/h/format change→true.
- `yaw_only`: pitch and roll dropped, yaw kept, unit quaternion.
- `quad_pose`: identity + 2.5 → z = −2.5.
- `drm_fourcc_to_vk`: the 4 codes, plus NV12 `0x3231564e` → None.
- `classify_system_err`: the three retry codes → `Retry`; `ERROR_VALIDATION_FAILURE` → `Xr`.
- `on_state`: READY→Begin, STOPPING→End, EXITING and LOSS_PENDING→Exit, FOCUSED→Nothing.
- `split_until_pid` (session.rs): `--until-pid` in the middle and at the end parse; a missing value → Err; a non-numeric value → Err.
  - Round trip, the argv the sidecar launcher sends: for a spec with every field set (e.g. `TabRev`, `Portal`, swap_eyes, `crop_aspect: Some(16.0/9.0)`, 3.5 m, 2.0 m) and for `ViewerSpec::default()`, `split_until_pid(spec.to_args() ++ ["--until-pid","4242"])` gives `(a, Some(4242))` and `ViewerSpec::from_args(&a) == Ok(spec)`.
- `Supervisor`: one case per rule above. Pid gone → `[Exit(0)]`; two `NoHeadset` ticks → one `waiting-headset` line and two `Wait(2s)`; `Shown` at the same size within 5s → no new line, after 5s → a new `showing` line; a size change → a new line at once; `Fatal` → `error` then `Exit(3)`; `SessionExit` → `Exit(0)`.

**Inline facts:**
- openxr `=0.22.0` (`loaded`), openxr-sys 0.14.0.
- ash `=0.38.0` (`loaded`). Extension modules: `ash::ext::{external_memory_dma_buf,image_drm_format_modifier,queue_family_foreign}`, `ash::khr::external_memory_fd`.
- **libc** `"0.2"` is a normal (non-optional) dependency of `crates/viewer/Cargo.toml` (WP-01), used for sigaction, dup, fstat, the pidfd syscall, poll and kill. The engine stays libc-free.
- `gpu.rs` (`pub mod import;`) and `xr.rs` (`pub mod session; pub mod swapchain; pub mod frame;`) are WP-01's, behind `#[cfg(feature="xr")]` in lib.rs.
- `FrameStream::end(&mut self, Time, EnvironmentBlendMode, &[&CompositionLayerBase<'_, G>])`; `EyeVisibility::{BOTH,LEFT,RIGHT}`.
- Host loader: `/usr/lib/libopenxr_loader.so.1.1.60`.
- Monado honours quad eyeVisibility (oxr_session_frame_end.c:161-176, comp_render_helpers.h:82-100).
- Do not set `XR_RUNTIME_JSON`.
- The §2 frame shape is `Plane{fd: OwnedFd, offset, stride}`, `FrameData::{Mem{stride, bytes}, DmaBuf{planes: Vec<Plane>, modifier}}` and `Frame{width, height, fourcc, seq, data}`. Read it from the merged `crates/viewer/src/frame.rs` before starting.
- Defaults: `--layout sbs --source auto`, 3 m wide, 2.5 m away (geo11-viewer.md:133). `to_args` omits the two f32 flags at 0.0, and main resolves 0.0 to 3.0 / 2.5.
