**The udev rule (new).** `packaging/flat3d-quest.rules`: one line that gives the logged-in user access to Meta USB devices (vendor `2833`, `TAG+="uaccess"`), the same access Quest Tether's own rule gives, under Flat to 3D's own file name. `install` copies it to `/etc/udev/rules.d/` and reloads udev with one sudo prompt, skips the step when the file is already there, and reports a refused or failed prompt as a Setup warning, not an install failure. `uninstall` removes the file. The exact commands are asserted in `install_plan.rs` (planned, not run); `install_execute.rs` runs them against a fake runner.

**Setup and doctor.** Setup keeps WiVRn, USB debugging and the seated boundary; step 5 is gone. The `doctor` command (WP-29) has no gnirehtet check and `setup install-apps` installs the WiVRn app only; WP-29 is written that way.
